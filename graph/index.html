What am I looking at?

  
Each dot is one file. The moving spark on a line shows which way the data travels — out of the file that provides it, into the file that uses it.

  
Just hover any dot to see what it takes data from, and what it sends data to.

  
Bigger dot = more files depend on it. No lines at all = nothing uses it.
